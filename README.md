# Faculty Appointment Scheduling System (CSE326)

Frontend-only project: HTML + CSS + JavaScript. Bookings are stored in the browser (localStorage).

## Run in VS Code
1. Open this folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension, right-click index.html, choose "Open with Live Server".
   (Or just double-click index.html to open it in a browser.)

## Files
- index.html: page structure, booking and slip dialogs
- style.css: layout, slot colours, print styles
- script.js: faculty data, filters, weekly grid, validation, booking, cancel, localStorage

## Deploy on GitHub Pages
Push the folder to a GitHub repo, then Settings > Pages > Deploy from branch (main, root).
